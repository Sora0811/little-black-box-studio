    Discord 連線

    依序貼上並檢查。這裡只驗證你貼上的內容，不會替你建立 webhook、bot 或訊息。

    1. 1　頻道 webhook

      Discord 頻道設定 → 整合 → Webhook → 新增 Webhook，複製網址。需要「管理 Webhook」權限。

    2. 2　Bot token（只有自動回覆需要）

      Developer Portal → 你的應用程式 → Bot：Reset Token，並開啟 Message Content Intent。邀請 bot 時給「檢視頻道」與「讀取訊息歷史」。

    3. 3　頻道與 intent

      頻道 ID 會在 webhook 通過後自動填入。這一步會讀取最近訊息，確認 bot 看得到文字內容。

      允許回覆的使用者

      勾選可以跟角色說話的人；其他人發言會被忽略。
